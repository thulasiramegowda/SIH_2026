# MANGANAI

### Satellite Intelligence for Manganese Prospectivity

MANGANAI is an AI and satellite-based decision-support system designed to identify and prioritize potential manganese exploration zones using Earth observation data and machine learning.

## Objective

To support mineral exploration by combining satellite-derived indicators, AI/ML analysis, and geospatial visualization to prioritize areas for further geological investigation.
